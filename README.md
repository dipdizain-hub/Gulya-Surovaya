# Книга вязания спицами — Гуля Суровая

Удобный **Mobile-First AgeTech** каталог проверенных описаний и схем вязания спицами, спроектированный специально для комфортного чтения и работы со смартфона (крупный шрифт, высокий контраст WCAG AAA, крупные кнопки с текстовыми подписями).

## Ключевые возможности сайта

1. **Комфортное чтение без нагрузки на глаза**:
   - Тёплая льняная палитра (`#FBF7F0`) без резкого белого свечения + **«Вечерний режим»** для вязания при мягком свете торшера.
   - Переключатель **«А+ Буквы»** (`20px` → `23px` → `26px`) с сохранением выбора.
   - Все кнопки высотой от `56px` с понятными русскими подписями и заметная кнопка **«← На главную / Назад в каталог»**.
2. **Голосовое чтение описаний вслух (`Web Speech API`)**:
   - Спокойный русский голос читает этапы и ряды по порядку с подсветкой активного шага.
   - Встроенный словарь вязальщицы автоматически расшифровывает сокращения (`лиц.`, `изн.`, `п.`, `2вм.лиц.`, `Sl1yo`, `DecR` и др.).
3. **Защита от гашения экрана (`Screen Wake Lock API`)**:
   - Экран телефона не блокируется сам, пока открыто описание или схема узора.
4. **Полноэкранное умное увеличение схем + линейка для ряда**:
   - Плавное увеличение жестом двух пальцев или крупными кнопками **«+ Крупнее» / «− Мельче»**.
   - Передвигаемая полупрозрачная янтарная **линейка ряда** (пальцем или кнопками `▲ Выше / ▼ Ниже`) + мини-счётчик рядов прямо поверх схемы.
5. **Встроенный счётчик рядов и отметки этапов**:
   - Сохраняется в памяти телефона (`localStorage`) отдельно для каждого описания и каждой детали (например, *Левый носок* и *Правый носок*), с защитой от случайного сброса.
   - На главной странице карточка **«Продолжить вязание»** возвращает к последнему открытому проекту и ряду в одно нажатие.
6. **Избранное («♥ Моё любимое») без паролей и регистрации**.
7. **Печать крупным шрифтом и архивные PDF**:
   - Специальный чистый режим печати крупным кеглем (`@media print`) + прямые ссылки на оригинальные PDF со схемами.
8. **Офлайн-режим (PWA / Service Worker)** — открытые описания и схемы работают даже при слабом интернете на даче.

## Состав пилотного запуска (Этап 1)

Перенесены 3 полных описания из 3 разных рубрик базы `БАЗА_ВЯЗАНИЕ_СПИЦАМИ` со всеми фотографиями, схемами и оригинальными PDF:
- **01 · Носки и следки**: *Носки спицами с растительным узором*
- **02 · Шапки, береты, капоры**: *Шапка в технике двухцветная бриошь*
- **04 · Манишки, снуды, бактусы и шали**: *Ажурная шаль «Цветочное Эхо» (Echo Flower Shawl)*
