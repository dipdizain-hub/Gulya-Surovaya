# Книга вязания спицами — Гуля Суровая

Удобный **Mobile-First AgeTech** каталог проверенных описаний и схем вязания спицами, спроектированный специально для комфортного чтения и работы со смартфона (крупный шрифт, высокий контраст WCAG AAA, чистое пространство экрана).

## Ключевые возможности сайта

1. **Компактная верхняя панель с автоскрытием**:
   - Аккуратные кнопки увеличения шрифта (**«А+»**: `20px` → `23px` → `26px`) и тёплого света (**«Вечер»**).
   - При прокрутке вниз верхний блок плавно уходит вверх, оставляя весь экран для описания, и сразу возвращается при движении вверх.
2. **Плавающая озвучка текста без обрывов (`Web Speech API`)**:
   - Изначально очень медленная и разборчивая скорость речи (**`0.6×`**) со словарём расшифровки вязальных сокращений (`лиц.`, `изн.`, `п.`, `2вм.лиц.`, `Sl1yo`, `DecR` и др.).
   - Чтение длинных абзацев целиком до последнего слова (разбивка по смысловым фразам).
   - Аккуратные плавающие кнопки управления сбоку экрана (`Пауза`, `Темп`, `Повтор`, `Дальше`, `Стоп`) — не нужно листать обратно наверх.
3. **Эстетичное мини-обучение при первом запуске**:
   - Ненавязчивые всплывающие подсказки появляются по мере прокрутки к нужным элементам внутри темы.
4. **Полноэкранный просмотр схем (портретный и горизонтальный режим)**:
   - Схема сразу открывается максимально крупно во весь экран (`100vw × 100dvh`), поддерживает поворот телефона в горизонтальный режим и увеличение двумя пальцами.
   - Всплывающая подсказка появляется на 12 секунд и сворачивается в небольшой кружок `?`: нажатие на кружок возвращает подсказку на 18 секунд, повторное нажатие на текст сразу скрывает её.
5. **Защита от гашения экрана (`Screen Wake Lock API`)**, **Избранное («♥ Моё любимое») без паролей**, **печать крупным шрифтом (`@media print`)**, оригинальные архивные PDF и работа офлайн (`Service Worker`).

## Состав пилотного запуска (Этап 1)

Перенесены 3 полных описания из 3 разных рубрик базы `БАЗА_ВЯЗАНИЕ_СПИЦАМИ` со всеми фотографиями, схемами и оригинальными PDF:
- **01 · Носки и следки**: *Носки спицами с растительным узором*
- **02 · Шапки, береты, капоры**: *Шапка в технике двухцветная бриошь*
- **04 · Манишки, снуды, бактусы и шали**: *Ажурная шаль «Цветочное Эхо» (Echo Flower Shawl)*
