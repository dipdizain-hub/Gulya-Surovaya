# Книга вязания спицами (редизайн 2026 · v3)

Персональная электронная книга проверенных описаний и схем вязания спицами, спроектированная для комфортного чтения на смартфоне и планшете пожилыми мастерицами.

## Ключевые особенности v3 (2026 AgeTech Flat Natural)

1. **Современный природный дизайн без визуального шума**:
   - Светло-кремовый фон (`#F7F6F1`), карточки мягкого белого цвета с деликатной воздушной тенью без резких рамок и эффекта «матрёшки», акцент приглушённого шалфея (`#3D6B58`) и светлый песочный (`#EFECE3`).
   - Современный округлый чёткий шрифт без засечек с тремя масштабами (`100%`, `Крупно`, `Макс.`) и тёплый вечерний режим.
2. **Главная страница, поиск и Избранное**:
   - В шапке главной страницы — крупная иконка «Сердечко», открывающая современное всплывающее окно Избранного с полупрозрачными скруглёнными карточками сохранённых тем.
   - Результаты поиска появляются сразу же под кнопкой поиска (ничто их не перекрывает).
   - Под кнопкой голосового поиска показывается подсказка о разрешении доступа к микрофону при первом запуске и автоматически исчезает после подтверждения.
3. **Страница описания во всю ширину экрана**:
   - Автоматически скрывающаяся при прокрутке вниз верхняя панель (`← Назад`, `А+`, `Вечер`) и возвращающаяся при прокрутке вверх.
   - Незаметная фоновая защита экрана от гашения (`Screen Wake Lock API`) без лишних плашек на странице.
4. **Надёжная озвучка «Читать вслух» (`0.6×`)**:
   - Лаконичная кнопка `🔊 Читать вслух` стоит непосредственно перед текстом описания и дочитывает весь текст до самого конца без обрывов на Android и iOS.
   - Аккуратные боковые плавающие кнопки (`Пауза`, `Темп`, `Повтор`, `Дальше`, `Стоп`), не перекрывающие текст.
5. **Схемы во весь экран**:
   - Схемы открываются максимально крупно на весь экран с поддержкой горизонтального поворота.
   - Всплывающая подсказка показывается на 12 секунд и сворачивается в маленький кружок `?`; нажатие на кружок возвращает её на 18 секунд, нажатие на текст скрывает сразу.
6. **Обучение в стиле матового стекла со стрелочкой**:
   - При первом визите показывается полупрозрачное облачко (`backdrop-filter: blur`) со стрелочкой, указывающей точно на кнопку «Читать вслух».

## Локальный запуск

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```
